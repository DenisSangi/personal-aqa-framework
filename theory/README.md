# theory/

Самостоятельные теоретические конспекты. Каждый — законченный артефакт (не абзац внутри задачи), на который ссылаются файлы-уроки из `../curriculum/`.

**Нумерация файлов** отражает порядок первого использования конспекта в `../curriculum/` (то есть порядок фаз `../PLAN.md`), а не дату написания. Номер закрепляется за темой навсегда: новые конспекты получают следующий свободный номер, уже выданные не перенумеровываются при вставке темы в середину — иначе ломались бы ссылки в закрытых уроках и журнале.

## Индекс

- [04-datetime-formatting.md](04-datetime-formatting.md) — `LocalDateTime`/`DateTimeFormatter`, буквы паттерна (`MM` vs `mm`), роль `Locale`, потокобезопасность `DateTimeFormatter` vs `SimpleDateFormat`. Опора для [P2-T2](../curriculum/P2-T2-datetime-util.md).

Опора для [P3-T1](../curriculum/P3-T1-base-element-input.md) и [P3-T2](../curriculum/P3-T2-button-dropdown-table.md).
- [06-page-object-and-navigation.md](06-page-object-and-navigation.md) — Page Object на минимальном примере, `return new NextPage()` для навигации, Lazy Initialization (`$`/`$x` не ищут элемент в момент вызова — только запоминают локатор), перенос Fluent Interface с уровня элемента на уровень страницы. Опора для [P4-T1](../curriculum/P4-T1-home-login-page.md).
- [07-testng-lifecycle-and-template-method.md](07-testng-lifecycle-and-template-method.md) — порядок хуков TestNG (`@BeforeSuite`…`@AfterSuite`), зачем `alwaysRun = true` на teardown, Template Method через наследование тестовых классов на изолированном примере (`Recipe`/`Omelette`/`Pancake`). Опора для [P6-T1](../curriculum/P6-T1-base-test-lifecycle.md).
- [08-observer-and-testng-listeners.md](08-observer-and-testng-listeners.md) — Observer на изолированном примере (`Button`/`ClickListener`), перенос на `ITestListener`/`@Listeners`, `Selenide.screenshot(...)`, разница между `@Listeners` и `@AfterMethod(ITestResult)`. Опора для [P6-T2](../curriculum/P6-T2-failure-screenshot-listener.md).
- [09-rest-assured-basics-and-adapter.md](09-rest-assured-basics-and-adapter.md) — `given()/when()/then()`, `RequestSpecification`, form-параметры vs JSON body, чтение ответа через `.jsonPath()` без модели, короткий перенос паттерна Adapter с Фазы 3 на API-слой. Опора для [P7-T1](../curriculum/P7-T1-rest-client-login-service.md).
- [10-records-builder-and-factory.md](10-records-builder-and-factory.md) — `record` (канонический/компактный конструктор, неизменяемость, все поля обязательны) vs Lombok `@Builder`/`@Builder.Default`/`toBuilder`, Factory на изолированном примере (`PizzaFactory`). Опора для [P7-T2](../curriculum/P7-T2-account-model-factory.md).
- [11-testng-dataprovider.md](11-testng-dataprovider.md) — механика `@DataProvider` (`Object[][]`, связка по имени, строка = отдельный запуск в отчёте), почему компилятор не проверяет связку (рефлексия, стирание типов), правило "один @Test = один класс исхода", отличие от JUnit 5 `@ParameterizedTest`. Опора для [P8-T1](../curriculum/P8-T1-dataprovider.md).
- [12-docker-and-postgres-basics.md](12-docker-and-postgres-basics.md) — образ vs контейнер (аналогия класс/объект), команды и флаги (`run`/`exec`/`logs`, `-d`/`-e`/`-p`/`-v`), проброс портов `хост:контейнер`, env-переменные образа Postgres, `/docker-entrypoint-initdb.d` и ловушка «только при первой инициализации», минимум DDL и `psql`. - [13-jdbc-basics.md](13-jdbc-basics.md) — JDBC как набор интерфейсов + драйвер, анатомия JDBC URL, `Statement` vs `PreparedStatement` и SQL-инъекции, `ResultSet` как курсор (`rs.next()`, нумерация с 1), `ResultSetMetaData` для универсального чтения колонок, `try-with-resources` для трёх ресурсов, `executeQuery` vs `executeUpdate`. Опора для [P9-T2](../curriculum/P9-T2-database-connection-util.md).
- [14-click-interception-and-stabilization.md](14-click-interception-and-stabilization.md) — механика hit-test при нативном WebDriver-клике, `ElementClickInterceptedException`, JS-клик и его компромисс, `Configuration.clickViaJs`, **перехват самого события клика JS-обработчиком** (раздел 5 — реальная причина на `automationexercise.com`, дописан по итогам P10-T3 как поправка к первоначальному диагнозу), разграничение "конфигурация фреймворка" vs "логика теста". Опора для [P10-T3](../curriculum/P10-T3-ui-stabilization.md).
- [15-testng-retry-and-annotation-transformer.md](15-testng-retry-and-annotation-transformer.md) — когда retry допустим, а когда маскирует дефекты; `IRetryAnalyzer` (счётчик, почему `count` не `static`, фильтрация по типу исключения и обход цепочки `getCause()` через обёртки Selenide); `IAnnotationTransformer` для применения ко всем тестам без правки каждого; регистрация через ServiceLoader (`META-INF/services/org.testng.ITestNGListener`) и почему `@Listeners` для трансформера не работает. Опора для [P10-T3](../curriculum/P10-T3-ui-stabilization.md).
- [16-threadlocal-driver-and-testng-parallel.md](16-threadlocal-driver-and-testng-parallel.md) — `ThreadLocal` на изолированном примере (продолжение идеи из `03-random-and-threadlocalrandom.md`), реальные классы Selenide, подтверждающие ThreadLocal-изоляцию WebDriver (`WebDriverThreadLocalContainer`/`ThreadLocalSelenideDriver`, найдены разбором jar-файла из зависимостей проекта), контраст с ДРУГИМ классом ThreadLocal-задачи на примере пула пользователей из референса, `parallel`/`thread-count` в TestNG, подключение `testng.xml` к Surefire, способ доказать реальную параллельность через имя потока. Опора для [P12-T1](../curriculum/P12-T1-threadlocal-parallel.md).
- [17-ci-and-jenkins-basics.md](17-ci-and-jenkins-basics.md) — что такое CI и что он даёт автотестам (цена отказа на нашем же примере P10-T2/P10-T3), устройство Jenkins (controller/agent/executor/plugins, Freestyle vs Pipeline), полная цепочка «push → джоба → `mvn clean test` на агенте → Allure», разбор декларативного `Jenkinsfile` по блокам (`agent`/`parameters`/`triggers`/`stages`/`post`/credentials), **три уровня формирования скоупа тестов** (реальный механизм референса — `${surefire.suiteXmlFile}` + 13 suite-файлов; TestNG groups; `-Dtest=`), триггеры и cron (включая `H` и зачем он), работа с результатом и flaky-тесты, короткая версия ответа для интервью.
