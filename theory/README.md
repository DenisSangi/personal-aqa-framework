# theory/

Самостоятельные теоретические конспекты. Каждый — законченный артефакт (не абзац внутри задачи), на который ссылаются файлы-уроки из `../curriculum/`.

## Индекс

- [maven-basics.md](maven-basics.md) — GAV-координаты, dependency vs plugin, scope, build lifecycle, структура папок, версия Java в pom.xml. Опора для [P0-T1](../curriculum/P0-T1-repo-maven-skeleton.md).
- [config-resolution.md](config-resolution.md) — `System.getenv()` vs `System.getProperty()`, порядок приоритета источников конфигурации, `Properties`+classpath, параллель с `Optional`. Опора для [P1-T1](../curriculum/P1-T1-config-facade.md).
- [random-and-threadlocalrandom.md](random-and-threadlocalrandom.md) — `java.util.Random` vs `ThreadLocalRandom`, проблема общего состояния при параллелизме, генерация случайных строк через диапазоны символов без внешней библиотеки. Опора для [P2-T1](../curriculum/P2-T1-random-generators.md).
- [datetime-formatting.md](datetime-formatting.md) — `LocalDateTime`/`DateTimeFormatter`, буквы паттерна (`MM` vs `mm`), роль `Locale`, потокобезопасность `DateTimeFormatter` vs `SimpleDateFormat`. Опора для [P2-T2](../curriculum/P2-T2-datetime-util.md).
- [selenide-basics-and-generics.md](selenide-basics-and-generics.md) — Selenide-основы (`$`/`$x`, `SelenideElement`, ленивый браузер, `click`/`selectOption`/`$$`/`ElementsCollection`), self-bounded generics (CRTP) на изолированном примере `Animal`/`Dog`, связь с Template Method. Опора для [P3-T1](../curriculum/P3-T1-base-element-input.md) и [P3-T2](../curriculum/P3-T2-button-dropdown-table.md).
- [page-object-and-navigation.md](page-object-and-navigation.md) — Page Object на минимальном примере, `return new NextPage()` для навигации, Lazy Initialization (`$`/`$x` не ищут элемент в момент вызова — только запоминают локатор), перенос Fluent Interface с уровня элемента на уровень страницы. Опора для [P4-T1](../curriculum/P4-T1-home-login-page.md).
- [testng-lifecycle-and-template-method.md](testng-lifecycle-and-template-method.md) — порядок хуков TestNG (`@BeforeSuite`…`@AfterSuite`), зачем `alwaysRun = true` на teardown, Template Method через наследование тестовых классов на изолированном примере (`Recipe`/`Omelette`/`Pancake`). Опора для [P6-T1](../curriculum/P6-T1-base-test-lifecycle.md).
- [observer-and-testng-listeners.md](observer-and-testng-listeners.md) — Observer на изолированном примере (`Button`/`ClickListener`), перенос на `ITestListener`/`@Listeners`, `Selenide.screenshot(...)`, разница между `@Listeners` и `@AfterMethod(ITestResult)`. Опора для [P6-T2](../curriculum/P6-T2-failure-screenshot-listener.md).
- [rest-assured-basics-and-adapter.md](rest-assured-basics-and-adapter.md) — `given()/when()/then()`, `RequestSpecification`, form-параметры vs JSON body, чтение ответа через `.jsonPath()` без модели, короткий перенос паттерна Adapter с Фазы 3 на API-слой. Опора для [P7-T1](../curriculum/P7-T1-rest-client-login-service.md).
- [records-builder-and-factory.md](records-builder-and-factory.md) — `record` (канонический/компактный конструктор, неизменяемость, все поля обязательны) vs Lombok `@Builder`/`@Builder.Default`/`toBuilder`, Factory на изолированном примере (`PizzaFactory`). Опора для [P7-T2](../curriculum/P7-T2-account-model-factory.md).
- [testng-dataprovider.md](testng-dataprovider.md) — механика `@DataProvider` (`Object[][]`, связка по имени, строка = отдельный запуск в отчёте), почему компилятор не проверяет связку (рефлексия, стирание типов), правило "один @Test = один класс исхода", отличие от JUnit 5 `@ParameterizedTest`. Опора для [P8-T1](../curriculum/P8-T1-dataprovider.md).
- [docker-and-postgres-basics.md](docker-and-postgres-basics.md) — образ vs контейнер (аналогия класс/объект), команды и флаги (`run`/`exec`/`logs`, `-d`/`-e`/`-p`/`-v`), проброс портов `хост:контейнер`, env-переменные образа Postgres, `/docker-entrypoint-initdb.d` и ловушка «только при первой инициализации», минимум DDL и `psql`. Опора для [P9-T1](../curriculum/P9-T1-docker-postgres-seed.md).
- [jdbc-basics.md](jdbc-basics.md) — JDBC как набор интерфейсов + драйвер, анатомия JDBC URL, `Statement` vs `PreparedStatement` и SQL-инъекции, `ResultSet` как курсор (`rs.next()`, нумерация с 1), `ResultSetMetaData` для универсального чтения колонок, `try-with-resources` для трёх ресурсов, `executeQuery` vs `executeUpdate`. Опора для [P9-T2](../curriculum/P9-T2-database-connection-util.md).
- [click-interception-and-stabilization.md](click-interception-and-stabilization.md) — механика hit-test при нативном WebDriver-клике, `ElementClickInterceptedException`, JS-клик и его компромисс, `Configuration.clickViaJs`, **перехват самого события клика JS-обработчиком** (раздел 5 — реальная причина на `automationexercise.com`, дописан по итогам P10-T3 как поправка к первоначальному диагнозу), разграничение "конфигурация фреймворка" vs "логика теста". Опора для [P10-T3](../curriculum/P10-T3-ui-stabilization.md).
- [testng-retry-and-annotation-transformer.md](testng-retry-and-annotation-transformer.md) — когда retry допустим, а когда маскирует дефекты; `IRetryAnalyzer` (счётчик, почему `count` не `static`, фильтрация по типу исключения и обход цепочки `getCause()` через обёртки Selenide); `IAnnotationTransformer` для применения ко всем тестам без правки каждого; регистрация через ServiceLoader (`META-INF/services/org.testng.ITestNGListener`) и почему `@Listeners` для трансформера не работает. Опора для [P10-T3](../curriculum/P10-T3-ui-stabilization.md).
