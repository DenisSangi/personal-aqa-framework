# P0-T1 — Скелет репозитория и Maven-тулинга

**Фаза / слой:** Фаза 0 — Скелет репозитория и тулинга (первая задача проекта)
**Теги:** java, maven

## Описание

Поднять рабочий, компилируемый Maven-проект в корне `personal-aqa-framework/` (там же, где уже лежат `PLAN.md`/`PROGRESS.md`/`curriculum/`/`theory/`) — без кода самого фреймворка, только тулинг:

- `pom.xml`: свои GAV-координаты, Java 17, зависимости Selenide + TestNG + Allure-адаптер под TestNG (`allure-testng`).
- Стандартная Maven-структура папок (`src/main/java`, `src/test/java`).
- Один placeholder-тест (например, класс с одним `@Test`, который просто проверяет `assertTrue(true)`) — чтобы было что реально прогнать и убедиться, что тестовый раннер подключён и работает.
- `.gitignore` под Java/Maven/IntelliJ (`target/`, `.idea/`, `*.iml` и т.п.).
- Git-репозиторий инициализирован в этой же папке, первый коммит.
- Публичный репозиторий на GitHub, запушено.

## Место в фреймворке

Ни от чего не зависит — это основание. От неё зависит буквально всё остальное: некуда будет класть конфиг (Фаза 1), утилиты (Фаза 2), элементы (Фаза 3) и т.д., пока нет рабочего `pom.xml`, который умеет их скомпилировать и прогнать тесты.

## Мотивировка

Без рабочего тулинга и воспроизводимой сборки: (а) нечего показать на портфолио — репозиторий, который не собирается у рекрутёра при `git clone && mvn test`, доверия не вызывает; (б) не с чем интегрировать остальные слои — каждая следующая задача добавляет зависимость или структуру поверх того, что заложено здесь, и если здесь заложено криво (например, забыт scope зависимости или неверная версия Java), это всплывёт на 5-10 задач позже в непонятной ошибке компиляции.

## Definition of Done

- [ ] `pom.xml` валиден, есть свои `groupId`/`artifactId`/`version`.
- [ ] Java 17 сконфигурирована (через `maven.compiler.release` или `source`+`target`).
- [ ] Зависимости добавлены: Selenide, TestNG, `allure-testng` (версии — актуальные стабильные, посмотреть на mvnrepository.com).
- [ ] Структура папок `src/main/java/...` и `src/test/java/...` создана (даже если `src/main` пока пуст).
- [ ] Один placeholder `@Test`-класс, который реально проходит.
- [ ] `mvn clean test` (или согласованный на ревью эквивалент, если `mvn` недоступен в окружении) — зелёный прогон.
- [ ] `.gitignore` на месте, ничего лишнего (`target/`, IDE-файлы) в git не закоммичено.
- [ ] Первый коммит сделан, публичный GitHub-репозиторий создан и запушен.
