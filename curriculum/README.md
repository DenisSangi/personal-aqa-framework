# curriculum/

Задачи-уроки. Один файл на задачу, создаётся в момент, когда задача реально даётся Денису (не заранее списком — см. `../PLAN.md` для дорожной карты id/названий).

## Схема файла-урока

```
# <id> — <заголовок>

**Фаза / слой:** ...
**Теги:** java / selenide / testng / rest-assured / sql / jenkins (можно несколько)

## Описание
Что построить.

## Место в фреймворке
Зависимости вверх/вниз — от чего опирается эта задача, что будет опираться на неё.

## Мотивировка
Зачем + цена отказа (в духе разделов «Без паттерна» из design-patterns.md).

## Теория
Нужные концепции + ссылка на файл в ../theory/.

## Definition of Done
Критерии приёмки.

## Типичные ошибки
Заполняется ПОСЛЕ ревью — реальные ошибки Дениса на этой задаче. Самая ценная секция для будущего веб-приложения.

## Ссылка на реальный код java-selenide-pp
Абсолютный путь к файлу(ам)-прообразу.
```

- [P8-T3 — Фикстура тестового пользователя на прогон](P8-T3-user-fixture.md) — ✅ **аппрувед 2026-08-17**, два автономных зелёных прогона подряд (32/32). Зависимость проекта от вручную созданного аккаунта на чужом стенде устранена полностью: `TestAccountFixture implements ISuiteListener` создаёт аккаунт в `onStart` через `AccountApiService`+`AccountFactory` и удаляет в `onFinish`; регистрация — строка в существующем `META-INF/services/org.testng.ITestNGListener`. Свойства `USERNAME`/`USER_EMAIL`/`USER_PASSWORD` **удалены** из `FrameworkConfig` и `framework.properties` — зелёный прогон после удаления и есть доказательство, что ручной аккаунт больше ни в чём не участвует. `loginAsDefaultUser()` → `loginAsValidUser(AccountModel)` (Facade получает пользователя параметром — решение границы `src/main` не видит `src/test`, Денис нашёл его сам). **Постановка изменилась по ходу:** предполагался `@BeforeSuite`, выбран `ISuiteListener` — «чтобы не забывать про новые сьюты». **Три замера харнессом:** `@DataProvider` вызывается после `@BeforeClass`, но до `@BeforeMethod` (отсекло вариант «фикстура на метод»); класс без `@Test` в suite-XML свои конфигурационные методы **выполняет** (уточняет урок P10-T4); падение `onStart` роняет прогон целиком и `onFinish` не вызывает (значит защитный `if` не нужен). Денис оспорил уровень фикстуры и сменил позицию под фактами референса (пул из 2 юзеров, создаваемых руками, а не аккаунт на тест). 7 находок ревью, среди них девятый случай «конструкция есть, физически не работает» (`return` из хука) и шестой случай ошибки в имени (`getName()` вместо `getFirstName()`).
