## Что произошло

Это первая сессия проекта `personal-aqa-framework` (открыт решением от 2026-07-22 — см. память `framework-build-routine.md`). `STARTING-PROMPT.md` описывает рабочий цикл как строго интерактивный: Tech Lead ставит одну задачу → обсуждает с Денисом до полного понимания → Денис пишет код сам → ревью → аппрув. Ни один из этих шагов невозможно честно выполнить без Дениса на связи — в частности, правило «никогда не писать его продакшн-код за него» напрямую запрещает сделать Задачу 1 за него, даже если бы формально пришло время её ставить.

Поэтому сессия использована на то, что Tech Lead ДЕЙСТВИТЕЛЬНО может подготовить в одиночку:

1. **Прочитаны опорные материалы**, на которые ссылается `STARTING-PROMPT.md`:
   - `Framework explanation/framework-layer-definition.md` — 7 слоёв архитектуры `java-selenide-pp`, направление зависимостей.
   - `Framework explanation/design-patterns.md` — все 14 паттернов с разделами «Без паттерна» (источник мотивировок для будущих задач).
   - `DatabaseConnectionUtil.java` — JDBC try-with-resources, `executeQuery` → `List<Map<String,String>>`.
   - Начало `ClinCardMergeCardholderSuccessfullyBaseClass.java` — конвенция `ParticipantState`, группировка полей по индексу сценария, balance-константы.
   - Память `denis-learning-style.md`, `qa-interview-prep.md` — стиль обучения и текущий контекст подготовки.

2. **Создан скелет бухгалтерии проекта** (папки/файлы, не код фреймворка):
   - `README.md` — обзор проекта.
   - `PLAN.md` — черновик фазовой дорожной карты: 14 фаз (Фаза 0 «Скелет репозитория» → ... → Фаза 13 «Финальный проход по паттернам»), ~20 задач верхнего уровня, каждая с id/зависимостью/мотивировкой одной строкой/теорией/тегом стека. **Не утверждён Денисом.**
   - `curriculum/README.md` — зафиксирована схема файла-урока (Описание / Место в фреймворке / Мотивировка / Теория / DoD / Типичные ошибки / ссылка на код) + пустой индекс.
   - `theory/README.md` — пустой индекс теоретических конспектов.

3. **Провизорно приняты 3 открытых решения** из `STARTING-PROMPT.md` (по рекомендованным умолчаниям, т.к. подтвердить их у Дениса сейчас невозможно):
   - Целевой сайт: `automationexercise.com`.
   - БД-тесты: локальный PostgreSQL в Docker + сид-данные.
   - Тест-раннер: TestNG.

   Явно помечены в `PLAN.md` как провизорные — первый пункт следующей живой сессии.
